# Security Policy

This repository is a **deliberately vulnerable training project** for the GitHub
Advanced Security (GH-500) certification. The code is not meant to be run or deployed,
so please don't report the planted vulnerabilities.

## Reporting a vulnerability

If you find something that is a real problem (a leaked real credential or a
misconfigured workflow, for example), use **Security → Report a vulnerability**
(private vulnerability reporting) instead of opening a public issue.
